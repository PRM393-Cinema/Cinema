\section{Introduction}\label{sec:srs-1}
\texttt{Cosmo\allowbreak{}Q} Cinema is one cinema booking and management system with multiple clients. This course-specific \texttt{SRS} refines consolidated \texttt{SRS} 2.0 using the current checkout; it does not define a second independent product. Executable routes/\allowbreak{}controllers/\allowbreak{}services/\allowbreak{}models take precedence over dated prose. \texttt{SRS} 1.0 is historical intent.

H = mandatory; M = important; L = optional. Implemented means source exists, not that integration tests passed. Each \texttt{EN}/\allowbreak{}\texttt{VI} pair uses identical IDs, scope, priority and criteria; neither language is a summary.
