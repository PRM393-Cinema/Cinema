\section{Out of Scope}\label{sec:srs-24}
Exclude native-only device work, store distribution and a hypothetical .\texttt{NET}-rendered \texttt{UI}. Native phone check-in belongs to Mobile; browser camera check-in belongs here.

No implemented \texttt{FCM} push or automatic bank-refund integration is claimed. Payroll, inventory and \texttt{AI} recommendations are not added.
